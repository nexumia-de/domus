# Fixtures

`1.json` and `300.json` are two entities of FlavorDB (`entities_json?id=1`, `?id=300`), read on
2026-11-23 through a fetch tool that passed the values on, with each molecule cut down to six of
its 41 fields. They are here so that the tests of `derive.mjs` run on the shape the site really
returns. Not proven by them: the fields that were cut, and entities with hundreds of molecules.

Data from FlavorDB, https://cosylab.iiitd.edu.in/flavordb2/, CC BY-NC-SA 3.0: Garg N et al.,
FlavorDB: a database of flavor molecules, Nucleic Acids Research, gkx957 (2017).
