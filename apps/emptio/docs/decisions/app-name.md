# The app is called Emptio, shown as Shopping List

## Context

The sister apps have a Latin repository name and a plain visible name:
Mixtura is "Drink Builder", Culina is "Cook's Notebook", their shared
model is materia.

## Decision

By the owner on 2026-11-18:

1. The repository is **Emptio**, the visible name **Shopping List**.
2. The umbrella of all apps is **Domus**, the visible name
   **Household**.
3. The shared package for code that touches the host is **hospes**,
   the package with the food catalogue **cibus**.

## Consequences

- "Shopping List" is descriptive and cannot be protected; it also
  cannot be taken away.
- The [name check](../name-check.md) found no collision in software for
  Emptio, hospes and cibus as used here. The trademark register counts
  about 3 marks for Emptio whose entries are not yet read.
- **Open**: an app named Domus for family organisation exists. Until
  the owner decides, Domus is used as a repository name only.
