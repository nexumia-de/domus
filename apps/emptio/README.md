# Emptio (Shopping List)

A shopping list for a household: every entry has a priority (now, soon,
sometime), the list sorts itself along the way through the store you
are in, and it knows what [Culina](../culina)
and [Mixtura](../mixtura) say is missing.
Free software, offline first, no account and no server of ours.

Status: plan and foundations; nothing to install yet. The plan is in
[docs/roadmap.md](docs/roadmap.md), how it is built in
[docs/architecture.md](docs/architecture.md), and why it exists in
[docs/existing-tools.md](docs/existing-tools.md).
