# Code name Mixtura, visible name Drink Builder

## Context

Apps of nexumia-de have a code name for repository and app id and a
visible name that says what the app does. Suggested code names were
Mixtura, Jigger, Swizzle and Coupe.

## Decision

The owner chose on 2026-11-16:

- code name **Mixtura** (Latin for mixture), next to Pensum and Culina;
- visible name **Drink Builder**, not "Cocktail …", because the app
  covers drinks without alcohol as well.

## Consequences

The names were checked on 2026-11-17 against the registries and stores
that could be reached; see [name check](../name-check.md). No serious
collision was found there, but the trademark registers (EUIPO, DPMA,
USPTO, WIPO), Google Play, the App Store and domain names could not be
searched because the hosts are blocked. "Drink Builder" is descriptive and
gives no exclusive right; "Mixtura" is distinctive but a common word, with
its trademark risk unknown. The owner searches the registers or orders a
professional check before the first release; status `needs decision` only
if that shows a hit.
